================================================================================
                            SECTION 1: APP OVERVIEW
================================================================================

FocusGuard is a comprehensive productivity and wellness mobile application built with React Native and Expo. The app is designed to help users build better habits, improve focus, and reduce digital distractions through an integrated suite of tools including smart alarms, motivational reminders, focus mode sessions, app blocking, day planning, and gamified progress tracking.

The core philosophy of FocusGuard is to make productivity feel rewarding and addictive through a sophisticated points system, achievements, streaks, and beautiful animations. Every interaction should feel premium, polished, and satisfying.

TARGET AUDIENCE:
- Students preparing for exams who need structured study schedules
- Professionals seeking to improve their work-life balance
- Anyone struggling with smartphone addiction or procrastination
- Users who want to build and maintain productive habits
- People who respond well to gamification and visible progress tracking

CORE VALUE PROPOSITIONS:
1. Integrated Experience: All productivity tools work together seamlessly
2. Gamification: Points, streaks, achievements, and leaderboards make productivity fun
3. Premium Design: Beautiful dark mode UI with smooth animations throughout
4. Smart Features: AI-powered insights and personalized recommendations
5. Flexibility: Highly customizable to fit any lifestyle or schedule

                    SECTION 4: ALARM CLOCK MODULE SPECIFICATION
================================================================================

The Alarm Clock is a core feature that helps users wake up purposefully. Unlike standard alarm apps, FocusGuard requires users to complete "dismiss tasks" to turn off the alarm, ensuring they are fully awake.

ALARM DATA MODEL:
```typescript
interface Alarm {
  id: string;                    // Unique identifier (UUID)
  time: string;                  // "HH:MM" format (24-hour)
  label: string;                 // Optional user label
  enabled: boolean;              // Is alarm active?
  repeatDays: number[];          // 0-6 (Sunday-Saturday), empty = one-time
  soundUri: string;              // Path to sound file or preset name
  vibrate: boolean;              // Enable vibration
  volume: number;                // 0-1 volume level
  snoozeEnabled: boolean;        // Allow snoozing
  snoozeDuration: number;        // Minutes per snooze
  maxSnoozes: number;            // Maximum allowed snoozes (1-5)
  gradualVolume: boolean;        // Gradually increase volume
  dismissTask: DismissTask;      // Task required to dismiss
  createdAt: string;             // ISO timestamp
  lastTriggered?: string;        // ISO timestamp
}

interface DismissTask {
  type: 'none' | 'math' | 'shake' | 'walk' | 'breathing' | 'typing' | 'barcode' | 'photo' | 'puzzle';
  
  // Math task settings
  mathDifficulty?: 'easy' | 'medium' | 'hard' | 'extreme';
  mathCount?: number;            // 1-10 problems to solve
  
  // Shake task settings
  shakeIntensity?: 'light' | 'medium' | 'vigorous';
  shakeDuration?: number;        // Seconds of shaking required
  
  // Walk task settings
  walkSteps?: number;            // 10-200 steps required
  
  // Breathing task settings
  breathingCycles?: number;      // 3-10 breath cycles
  inhaleSeconds?: number;        // 4-8 seconds
  holdSeconds?: number;          // 0-8 seconds
  exhaleSeconds?: number;        // 4-8 seconds
  
  // Typing task settings
  typingText?: string;           // Custom phrase to type
  caseSensitive?: boolean;       // Require exact case match
}
```

ALARM STORE ACTIONS:
- addAlarm(alarm: Partial<Alarm>): Add new alarm with defaults
- updateAlarm(id: string, updates: Partial<Alarm>): Modify existing alarm
- deleteAlarm(id: string): Remove alarm
- toggleAlarm(id: string): Enable/disable alarm
- getNextAlarm(): Get the next scheduled alarm
- triggerAlarm(id: string): Mark alarm as triggered
- duplicateAlarm(id: string): Create a copy of an alarm

```typescript
interface FocusSession {

  endTime?: string;              // ISO timestamp when ended

  actualDuration: number;        // Actual focused time in minutes

  distractions: DistractionEvent[]; // Track distraction attempts

  sound: string | null;          // Ambient sound used

interface PauseEvent {
```

The App Blocker helps users limit access to distracting applications. Due to platform limitations in React Native/Expo, this feature operates as a tracking and reminder system rather than true system-level blocking.

APP BLOCKER DATA MODEL:
```typescript
interface BlockedApp {
  packageName: string;           // Unique app identifier
  appName: string;               // Display name
  appIcon?: string;              // Emoji or local image path
  dailyLimitMinutes: number;     // Daily usage limit (0 = always blocked)
  todayUsageMinutes: number;     // Today's tracked usage
  trackingEnabled: boolean;      // Track usage time
  reminderEnabled: boolean;      // Show reminders when approaching limit
  scheduleBlocked: boolean;      // Block during scheduled hours
  blockSchedule?: BlockSchedule; // When to block
  unlockTask: UnlockTask;        // Task to unlock temporarily
  blockMessage: string;          // Custom message when blocked
  blockImageUri?: string;        // Custom image for block screen
  streakDays: number;            // Days under limit
}

interface BlockSchedule {
  enabled: boolean;
  startTime: string;             // "HH:MM"
  endTime: string;               // "HH:MM"
```

The points system gamifies productivity, making habit-building addictive and rewarding through visible progress and achievements.

POINTS ACTIONS:

Earning Points:
| Action                          | Points | Notes                         |
|---------------------------------|--------|-------------------------------|
| Wake up (no snooze)             | +50    | Alarm dismissed immediately   |
| Wake up (1-2 snoozes)           | +25    | Reduced reward                |
| Start a task                    | +15    | Begin working on planned task |
| Complete focus session          | +40    | Finish scheduled session      |
| Complete task (all sessions)    | +100   | Finish entire task            |
| Partial task completion (50%+)  | +50    | Complete at least half        |
| No distractions bonus           | +25    | Session without app opens     |
| Daily goal reached              | +75    | Earn target points for day    |
| Streak day bonus                | +10×n  | n = current streak day        |
| Read reminder                   | +5     | Engage with reminder          |
| Stay under app limit            | +20    | Daily limit not exceeded      |

Deducting Points:
| Action                          | Points | Notes                         |
|---------------------------------|--------|-------------------------------|
| Snooze alarm                    | -10    | Per snooze                    |
| End session early               | -30    | Cancel before completion      |
| Skip planned task               | -25    | Mark task as skipped          |
| Exceed app limit                | -15    | Go over daily usage limit     |
| Miss reminder                   | -5     | Ignore scheduled reminder     |

DAILY GOAL SYSTEM:
- Default daily goal: 200 points
- Adjustable in settings (100-500)
- Progress bar on home/stats
- Push notification at 90% progress
- Celebration animation at goal

STREAK SYSTEM:
- A "productive day" requires earning daily goal
- Streak increments each consecutive productive day
- Streak resets if goal not met
- Streak protection: One free skip per week
- Streak milestones celebrate at 7, 30, 100 days

LEVEL SYSTEM (Optional Feature):
- Level based on total points
- Each level requires more points
- Level 1: 0 points

- Level 3: 1,500 points
- Level n: exponential growth
- Level badges and titles
